Native macOS file manager

Commander

A fast, keyboard-first two-pane file manager for macOS, inspired by the classic Far Manager workflow.

Download latest release View source on GitHub

macOS 13 or later · Apple silicon and Intel · Developer ID signed and notarized

Two panes

Navigate and work with two directories side by side.

Keyboard first

Familiar function-key commands and efficient keyboard navigation.

Native macOS

A native Swift application distributed as a signed and notarized universal app.

Install

Download the latest DMG, open it, and drag Commander.app to Applications.
